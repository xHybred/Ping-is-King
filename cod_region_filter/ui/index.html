Evaluation

The order rules are applied.

  1. Game servicesAuth, lobby, ownership and content servers are always allowed.
  2. DenyExplicit blocks win over region rules.
  3. PinsNamed ranges stay reachable.
  4. AllowCluster, region, country or radius match.
  5. Ping limitOptional ceiling on measured round-trip.
  6. DefaultAllowlisted mode blocks located servers not matched above.

Application

Version and environment.

Filtering works by dropping game packets at the Windows packet layer. It does not modify the game or its memory. Call of Duty's terms give Activision the right to restrict network manipulation, so use this at your own risk.
